# القرآن بالأوامر الصوتية

تطبيق ويب عربي بسيط (HTML + CSS + JavaScript فقط، بدون أي مكتبة خارجية) لتشغيل
سورة الفاتحة **بالأوامر الصوتية**، مصمَّم خصيصاً للمكفوفين وضعاف البصر
ومتوافق مع قارئات الشاشة (NVDA / JAWS / Narrator / VoiceOver).

> هذه النسخة الأولى تعمل بالتحكّم الصوتي فقط (بدون أزرار تشغيل يدوية).

## بنية المشروع

```
QuranVoice/
├── index.html      واجهة عربية RTL متوافقة مع قارئات الشاشة (قسم واحد: التحكّم الصوتي)
├── style.css       أنماط عالية التباين وحالة تركيز واضحة ودعم الوضع الفاتح/الداكن
├── app.js          منطق التشغيل + Web Speech API
├── serve.ps1       خادم محلي لويندوز (لأن الميكروفون لا يعمل مع file://)
└── audio/
    └── 001.wav / 001.mp3   ملف السورة (يُفضَّل WAV، ويُقبل MP3)
```

## التشغيل على ويندوز

### الطريقة الأولى (الأسهل): PowerShell

1. افتح مجلد المشروع في **PowerShell** (مرّر المجلد في شريط عنوان Explorer واكتب
   `powershell` ثم Enter).
2. نفّذ:

   ```powershell
   .\serve.ps1
   ```

   > إن ظهرت رسالة «تم حظر تشغيل السكربت»، نفّذ هذا مرة واحدة ثم أعد المحاولة:
   > ```powershell
   > Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
   > ```

3. سيفتح المتصفح تلقائياً على **http://localhost:8080**
   (باستخدام Edge: `.\serve.ps1 -Browser edge` — وتغيير المنفذ: `-Port 8081`).
4. اضغط `Ctrl+C` في نافذة PowerShell لإيقاف الخادم.

### الطريقة الثانية: Chrome مباشرة (بدون خادم)

اسحب `index.html` إلى Chrome.

- ⚠️ **التحكّم الصوتي لن يعمل** لأن المتصفحات تمنع استخدام الميكروفون من `file://`.
  استخدم الطريقة الأولى لتجربة الأوامر الصوتية.

### الطريقة الثالثة: Python (إن كان مثبتاً)

```powershell
python -m http.server 8080
# ثم افتح http://localhost:8080
```

## طريقة الاختبار

### 1. اختبار أساسي

1. افتح **http://localhost:8080** في **Chrome** أو **Edge** (التحكّم الصوتي مدعوم فيهما).
2. انتقل بـ `Tab` إلى زر **«🎙️ بدء الإصغاء للأوامر الصوتية»** — تظهر حدّة تركيز صفراء واضحة.
3. اضغط `Enter`. يجب أن يطلب المتصفح إذن الميكروفون — **اسمح** باستخدامه.
4. الحالة تتحوّل إلى: **«حالة الميكروفون: أستمع الآن… قل ‹الفاتحة›»**.

### 2. اختبار الأوامر الصوتيّة

قل بصوت واضح أحد الأوامر، وراقب ما يظهر في سطر «سمعتُ: …» ثم ما يحدث:

| الأمر | النتيجة المتوقّعة |
|---|---|
| **«الفاتحة»** | يبدأ تشغيل السورة من البداية |
| **«إيقاف»** أو **«توقف»** | إيقاف مؤقت |
| **«استئناف»** أو **«تابع»** | متابعة التشغيل |
| **«إعادة»** أو **«من البداية»** | إعادة التشغيل من أولها |
| **«اصمت»** أو **«إيقاف الاستماع»** | إطفاء الميكروفون |

يُفضَّل: استعمل **Chrome** أو **Edge** (كلاهما يدعم Web Speech API)،
واعمل **متصلًا بالإنترنت** لأن خدمة التعرّف على الكلام ترسل الصوت إلى خوادم المزوّد.
بقية ميزات التطبيق تعمل بلا إنترنت.

### لماذا أثناء التشغيل يُسمع التطبيق أمر «إيقاف» فقط؟

الميكروفون يبقى مفتوحاً أثناء التشغيل، فيلتقط أحياناً **صوت التلاوة الخارج من
سماعة الهاتف**. لو فسّرنا ذلك كأمر، لتكرّرت دورة التشغيل/الإيقاف وتقطّع الصوت
(تغذية راجعة صوتية). لذلك:

- أثناء التشغيل: تُقبل **«إيقاف»/«توقف»** و**«اصمت»** فقط، وتُتجاهل بقيّة الجمل.
- بعد الإيقاف: تعود كلّ الأوامر (استئناف، إعادة، تشغيل) فعّالة كالمعتاد.

**لتقليل هذه الظاهرة أكثر:** استخدم سمّاعات رأس أو اخفض صوت السماعة، فيقلّ ما
يلتقطه الميكروفون من التلاوة.

### 3. اختبار قارئ الشاشة (NVDA مثلاً)

1. شغّل NVDA ثم افتح الصفحة.
2. استخدم `H` للانتقال إلى عنوان «التحكّم الصوتي».
3. انتقل بـ `Tab` إلى الزر — يجب أن يُقرأ اسمه بصوته العربي.
4. اضغط `Enter`، ويجب أن يعلن قارئ الشاشة رسالة البداية:
   «بدأ الإصغاء. قل: الفاتحة، أو إيقاف، أو استئناف، أو إعادة».
5. عند تعذّر الإذن، يُعلن: «لم يُسمح باستخدام الميكروفون…».

### 4. اختصار لوحة المفاتيح

- <kbd>V</kbd> — تشغيل / إيقاف الميكروفون.
- <kbd>Tab</kbd> — التنقّل بين العناصر.

## استبدال الملف الصوتي

ضع الملف داخل `audio/` باسم `001` مع أحد الامتدادات:

- `001.wav` — الصيغة المفضّلة، تُجرَّب أولاً من `<source>` في `index.html`.
- `001.mp3` — يُستخدم تلقائياً إن لم يوجد ملف WAV بنفس الاسم.

لا حاجة لتعديل الواجهة إذا التزمت بهذا الاسم. ولأسماء أخرى عدّل قائمة `<source>`:

```html
<audio id="quran-audio" preload="metadata">
  <source src="audio/002.wav" type="audio/wav">
  <source src="audio/002.mp3" type="audio/mpeg">
</audio>
```

## ملاحظات تقنية

- يُفضَّل تشغيل ملفات WAV مباشرة دون تحويل، مع قبول MP3 كبديل تلقائي.
- سطر `404` على `001.wav` في وحدة تحكم المتصفح **متوقّع وغير ضار** ما دام ملف MP3 موجوداً: المتصفح يجرّب WAV ثم يسقط إلى MP3.
- `preload="metadata"` يجعل المتصفح يقرأ بيانات المدة فقط دون تنزيل الملف كاملاً.
- كل عناصر الواجهة تحتوي `aria-*` صحيحة، ومنطقة إعلانات
  `role="status" aria-live="polite"` تُبلغ قارئ الشاشة بأي تغيّر في الحالة.
- دالة التطبيع العربي تزيل التشكيل والتطويل وتوحّد الألف والهمزات والتاء المربوطة
  كي تُفهم صيغ مثل «استئناف» و«إيقاف» بغضّ النظر عن الكتابة.
- `prefers-reduced-motion` و`prefers-color-scheme` مدعومان.
- **الخطوة التالية بعد نجاح الاختبار:** إضافة بقية السور (002.wav …) بقائمة اختيار
  أو بأمر صوتي يذكر رقم/اسم السورة.
